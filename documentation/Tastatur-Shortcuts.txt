FRAME-NAVIGATION
----------------
  Pfeil rechts / links    -> einen Frame vor / zurück
  Bild-Auf / Bild-Ab      -> 10 Frames vor / zurück
  Pos1 / Ende             -> erster / letzter Frame
  Leertaste               -> Wiedergabe starten/pausieren


MESSBEREICHE (ROI) ZUM PLATZIEREN WÄHLEN
----------------------------------------
  Ziffer 1-6              -> "Oben", "Links", "Mitte", "Rechts", "Unten",
                             "Hintergrund"
  Ziffer 7, 8, 9, 0       -> selbst angelegte Messbereiche Nr. 7, 8, 9, 10

Wirkt wie ein Klick auf "Messbereich setzen": der nächste Klick ins Bild
platziert den Messbereich dort.


HINWEISE
--------
- Alle Tasten wirken nicht, solange in ein Text- oder Zahlenfeld getippt
  wird. Erst nach Verlassen des Feldes (Klick woanders hin oder Tab) sind
  sie wieder aktiv.
- Ist ein Knopf oder eine Checkbox fokussiert, schaltet die Leertaste
  stattdessen genau dieses Element um.
- Rückgängig / Wiederholen: Strg+Z / Strg+Y.


MAUS IM BILD
------------
  Linksklick              -> Live-Cursor an dieser Stelle fixieren
  Rechtsklick             -> Fixierung wieder lösen

Bei aktivem Maßstab-Werkzeug ("Werkzeuge > Maßstab festlegen…"):

  Linksklick              -> Start- bzw. Endpunkt der Referenzlinie setzen
  Rechtsklick             -> Werkzeug abbrechen

Bei bereits gesetztem Maßstab:

  Endpunkt ziehen         -> Endpunkt verschieben (reale Länge bleibt)
  Doppelklick auf Linie   -> reale Länge ändern

Im Reiter "Querschnitte" lässt sich jede Linie im Bild per Ziehen
verschieben.
