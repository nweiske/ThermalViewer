1. WAS IST DAS?
================================================================

Der Thermo-Sequenz-Viewer zeigt eine Serie von Thermokamera-Messungen
(einzelne CSV-Dateien, je eine pro Zeitpunkt) als "Video" an und lässt
zusätzlich beliebig viele frei platzierbare, in Breite und Höhe
unabhängig skalierbare Messbereiche (ROIs, standardmäßig 5) definieren.
Für jeden Messbereich wird der gemittelte Temperaturwert über alle
geladenen Zeitpunkte hinweg als Graph dargestellt.

Zusätzlich kann man mit der Maus über das Bild fahren und sieht live
den Temperaturverlauf des Pixels unter dem Mauszeiger über alle Frames.

2. PROGRAMM STARTEN
================================================================

Es gibt zwei Varianten:

  a) Fertige ausfuehrbare Datei (empfohlen fuer normale Nutzung)
     Unter Windows: Doppelklick auf ThermalViewer.exe. Es gibt zwei
     Ausgaben:
       - ThermalViewer-<version>-windows10-11.zip    (Windows 10/11)
       - ThermalViewer-<version>-windows7-legacy.zip (Windows 7)
     Falls unsicher, welche exe zum eigenen Rechner passt: die
     "windows10-11"-Variante zuerst probieren. Startet sie nicht, die
     "windows7-legacy"-Variante verwenden.

     Unter Linux: ThermalViewer-<version>-linux.tar.gz entpacken, dann
     in einem Terminal einmalig "chmod +x ThermalViewer" ausfuehren und
     danach per Doppelklick oder "./ThermalViewer" starten. Setzt die
     ueblichen Qt-Laufzeitbibliotheken voraus (u.a. libgl1, libegl1,
     libxkbcommon0, die libxcb-*-Pakete, libdbus-1-3, libfontconfig1 -
     unter Debian/Ubuntu z.B. per "sudo apt install libgl1 libegl1
     libxkbcommon0 libdbus-1-3 libfontconfig1" nachinstallierbar).

  b) Aus dem Quellcode (fuer Entwicklung)
     Voraussetzung: Python-Paketverwaltung "uv" installiert.
     Im Projektordner in der Konsole:

         uv run python run.py

     Beim ersten Start werden automatisch alle benoetigten
     Abhaengigkeiten installiert.

3. MESSREIHE(N) LADEN
================================================================

Über die Symbolleiste oben oder das Menü "Datei":

  - "Ordner öffnen..."   -> laedt ALLE *.csv-Dateien aus einem Ordner
                            als zeitliche Abfolge (Video).

Die Reihenfolge der Frames ergibt sich automatisch aus dem Zeitstempel
im Dateinamen (siehe Abschnitt 15). Nach dem Laden erscheint der erste
Frame im Bildbereich, und die Statuszeile unten zeigt an, wie viele
Frames geladen wurden.

HINWEIS: Tragen mehrere Dateien exakt denselben Zeitstempel im Namen
(z.B. weil eine Datei per Windows-Kopie vervielfaeltigt und nicht
umbenannt wurde), erscheint eine Warnung. Das Programm funktioniert
trotzdem, die Zeitachse wird dann intern minimal (Millisekunden)
auseinandergezogen, damit die Graphen sinnvoll aussehen.

HINWEIS: Ist eine einzelne CSV-Datei kaputt/unlesbar (z.B. abgebrochener
Schreibvorgang) oder hat eine abweichende Bildaufloesung als der Rest der
Messreihe, bricht das Laden NICHT komplett ab. Die betroffene(n) Datei(en)
werden automatisch uebersprungen, eine Warnung listet sie mit Grund auf,
und die restliche (gueltige) Messreihe wird ganz normal geladen.

NAMENSSCHEMA NICHT ERKANNT: Passt beim "Ordner öffnen..." KEINE der
".csv"-Dateien im gewaehlten Ordner zum erwarteten Namensschema
(Standard: "Record_YYYY-MM-DD_hh-mm-ss", siehe Abschnitt 15), erscheint
eine Rueckfrage mit drei Möglichkeiten:

  - "Neuen Ordner wählen"      -> oeffnet erneut die Ordnerauswahl.
  - "Namenstemplate anpassen…" -> oeffnet ein Fenster, in dem das
                                   tatsaechliche Namensschema eingegeben
                                   werden kann, z.B. "IMG_YYYY-MM-DD_
                                   hh-mm-ss" fuer Dateien wie
                                   "IMG_2026-08-24_14-30-00.csv".
                                   Platzhalter (Groß-/Kleinschreibung
                                   beachten): YYYY=Jahr, MM=Monat,
                                   DD=Tag, hh=Stunde, mm=Minute,
                                   ss=Sekunde (jeweils 2-stellig, YYYY
                                   4-stellig) -- alle anderen Zeichen
                                   muessen genau so im Dateinamen stehen.
                                   Darunter zeigt eine LIVE-VORSCHAU
                                   sofort, welche der tatsaechlich im
                                   Ordner vorhandenen CSV-Dateien zum
                                   gerade eingegebenen Schema passen
                                   wuerden (Speichern erst moeglich, wenn
                                   mindestens eine Datei passt). Ein
                                   Haken "Als neues Standard-Namensschema
                                   dauerhaft speichern" (Standard: AUS)
                                   legt fest, ob das neue Schema nur fuer
                                   diesen einen Ladevorgang gilt (danach
                                   wieder das bisherige Schema) oder
                                   dauerhaft als neuer Standard verwendet
                                   wird.
  - "Abbrechen"                -> bricht den Ladevorgang ab.

LIVE-ORDNER UEBERWACHEN: Nach "Ordner öffnen..." laeuft automatisch im
Hintergrund eine Live-Ueberwachung dieses Ordners, damit die App
parallel zu einer noch laufenden Messung genutzt werden kann -- ohne
dass dafuer etwas extra eingeschaltet werden muss. Alle 10 Sekunden wird
geprueft, ob im geoeffneten Ordner neue CSV-Dateien abgelegt wurden, und
diese werden automatisch nachgeladen - ohne die aktuelle Wiedergabe-
position zu stoeren. War die Anzeige zuvor bereits beim letzten Frame
(typisches "live mitschauen"), springt sie nach dem Nachladen
automatisch zum jeweils neuesten Frame mit; wurde zuvor ein frueherer
Frame betrachtet, bleibt die Position unveraendert. Das feste
10-Sekunden-Intervall (statt sofortiger Reaktion auf jede neue Datei)
verhindert, dass die App bei sehr haeufig abgelegten Dateien (z.B. alle
500 ms) durch staendiges Nachladen unbenutzbar wird.

DATENIMPORT-MANAGER (ABWEICHENDES DATEIFORMAT): Das Namensschema oben
betrifft nur den DATEINAMEN. Weicht stattdessen der INHALT der Dateien
vom erwarteten Rohformat ab (Standard: ';'-getrennt, Dezimalkomma, keine
Kopf-/Fusszeilen, keine zusaetzlichen Spalten) -- z.B. bei Messreihen aus
einer anderen Quelle/einem anderen Geraet --, schlaegt das Laden fehl und
es erscheint eine Rueckfrage "Daten konnten nicht gelesen werden" mit der
Option "Datenimport anpassen...". Das oeffnet den DATENIMPORT-MANAGER:

  - "Trennzeichen"            -> Semikolon, Komma, Tabulator, senkrechter
                                  Strich oder beliebig viele Leerzeichen.
  - "Dezimaltrennzeichen"     -> Komma oder Punkt.
  - "Zeichenkodierung"        -> UTF-8 (Standard), Windows-1252/Latin-1
                                  oder UTF-16.
  - "Kopfzeilen überspringen" -> Anzahl der Zeilen am Dateianfang ohne
                                  Messwerte (z.B. Geraete-/Datumsangaben).
  - "Fußzeilen überspringen"  -> ebenso am Dateiende.
  - "Erste/Letzte Spalte(n)
     entfernen"                -> z.B. eine fuehrende Index-/Zeilennummer-
                                  Spalte, die keine Messwerte enthaelt.

Links zeigt eine Beispieldatei ("Andere Datei wählen..." erlaubt einen
Wechsel) die rohen ersten Zeilen, rechts/darunter sofort das ERGEBNIS der
aktuellen Einstellung: entweder die erkannte Zeilen-/Spaltenzahl mit
einem Ausschnitt der geparsten Werte, oder eine Fehlermeldung, falls die
Einstellung (noch) nicht passt. "OK" ist erst waehlbar, sobald die
Beispieldatei erfolgreich gelesen werden konnte. Ein Haken "Als neue
Standardeinstellung dauerhaft speichern" (Standard: AUS) legt fest, ob
die Anpassung nur fuer diesen einen Ladevorgang gilt oder dauerhaft als
neuer Standard uebernommen wird. Nach dem Bestaetigen versucht die App
automatisch erneut zu laden; passt es immer noch nicht, erscheint dieselbe
Rueckfrage erneut.

Der Datenimport-Manager laesst sich auch VORAB -- unabhaengig von einem
fehlgeschlagenen Ladevorgang -- über "Werkzeuge > Datenimport
anpassen..." öffnen (z.B. um sich auf eine neue, noch unbekannte
Messreihen-Quelle vorzubereiten, bevor ueberhaupt geladen wird). Ist
bereits eine Messreihe geladen, dient deren erste Datei als Beispiel,
sonst fragt eine Dateiauswahl danach.


================================================================
4. DER BILDBEREICH (LINKS)
================================================================

Im linken, zentralen Bereich wird der aktuelle Frame als Falschfarben-
bild dargestellt. Rechts daneben liegt die Legende (Farbskala).

Das Bild selbst laesst sich absichtlich NICHT mit der Maus verschieben
oder zoomen - alle relevanten Messdaten befinden sich immer vollstaendig
im sichtbaren Bereich. Lediglich die Messbereiche (ROIs, siehe unten)
lassen sich per Maus verschieben und in der Groesse aendern.

Direkt am Cursor-Kreuz im Bild wird zusaetzlich die Temperatur DES
AKTUELLEN Bildpunkts eingeblendet (z.B. "23,4 °C") - dieselbe Stelle,
die auch im Live-Graph (Abschnitt 8) verfolgt wird. Der Wert
aktualisiert sich automatisch mit: bei Mausbewegung ueber ein anderes
Pixel ebenso wie beim Wechsel auf einen anderen Frame waehrend der
Wiedergabe (auch ohne die Maus zu bewegen) - so laesst sich die
Temperatur an einer fixierten Stelle live waehrend des Abspielens
mitverfolgen.

Ueber "Ansicht > Dunkelmodus" (ein einzelner an-/abwaehlbarer Menuepunkt)
laesst sich zwischen hellem und dunklem Erscheinungsbild wechseln -
gilt einheitlich fuer die gesamte Oberflaeche INKLUSIVE Thermobild und
Kurven-Graphen. Die Wahl wird gespeichert und beim naechsten Start
automatisch wieder eingestellt.

5. FRAME-NAVIGATION UND WIEDERGABE
================================================================

Die Zeitleiste befindet sich UNTERHALB des Thermobilds (nicht mehr in
einer Symbolleiste oben) und ist genauso breit wie das Bild selbst:

  - Play-Knopf (Dreieck)    -> spielt die Sequenz automatisch ab
  - Schieberegler "Frame"   -> springt direkt zu einem bestimmten Frame
  - Zahlenfeld daneben      -> zeigt/setzt die Frame-Nummer
  - FPS-Feld                -> Abspielgeschwindigkeit (Frames pro Sekunde)

Der aktuelle Zeitstempel des angezeigten Frames steht rechts daneben.
Die Wiedergabe stoppt automatisch am letzten Frame. Erneutes Klicken auf
Play, nachdem das letzte Bild erreicht wurde, startet die Wiedergabe
wieder von vorne (Frame 1).

Zusaetzlich per Tastatur bedienbar (solange kein Text-/Zahlenfeld gerade
editiert wird):

  - Pfeil rechts / links   -> einen Frame vor / zurueck
  - Bild-Auf / Bild-Ab     -> 10 Frames vor / zurueck
  - Pos1 / Ende            -> zum Auswertungsstart / zum Auswertungsende
                              springen (Abschnitt 6, standardmaessig
                              erster/letzter geladener Frame, beide
                              manuell korrigierbar)
  - Leertaste              -> Wiedergabe starten/pausieren (wie Play-Knopf).
                              Bleibt dabei standardmaessig auf den
                              Auswertungsbereich (Start bis Ende, siehe
                              Abschnitt 6) begrenzt: steht der Regler beim
                              Start bereits AUSSERHALB dieses Bereichs, laeuft
                              die Wiedergabe stattdessen ungeklemmt bis zum
                              tatsaechlich letzten Frame.

Eine separate Kurzreferenz aller Tastatur-Shortcuts liegt in
Tastatur-Shortcuts.txt (gleicher Ordner wie diese Datei).

6. MESSBEREICHE (ROI) ANLEGEN UND BEARBEITEN
================================================================

Im rechten Panel "ROI & Legende" gibt es links eine senkrechte Liste,
einen Eintrag pro Messbereich, per Klick auswaehlbar -- rechts daneben
die Detailansicht des jeweils ausgewaehlten Messbereichs. Das spart
Platz, da ROI-Namen meist kurz sind. Standardmaessig sind fuenf
Messbereiche angelegt, benannt nach ihrer typischen Anordnung: "Oben",
"Links", "Mitte", "Rechts" und "Unten" (in dieser Reihenfolge). Ueber den
Knopf "+ Messbereich" oberhalb der Liste lassen sich beliebig viele
weitere hinzufuegen -- jeder neue Messbereich hat exakt dieselben
Funktionen wie die urspruenglichen fuenf und heisst zunaechst "ROI n". Die
Trennlinie zwischen Liste und Detailansicht laesst sich per Maus
verschieben. Das GESAMTE Panel (Legende, Maßstab und die ROI-Auswahl)
sitzt in einem gemeinsamen Scrollbereich, damit bei knappem Platz alles
erreichbar bleibt.

Jeder Listeneintrag zeigt direkt VOR dem Namen ein Haekchen zum Ein-/
Ausblenden dieses Messbereichs (Rechteck, Beschriftung, Graph-Kurve) --
ohne ihn zu loeschen. Der Name selbst laesst sich per DOPPELKLICK auf den
Eintrag direkt umbenennen; leer gelassen faellt er automatisch auf den
Standardnamen zurueck. Ein Messbereich laesst sich auf zwei Arten
auswaehlen (beide fuehren zum selben Ergebnis und aktivieren automatisch
"Messbereich setzen", siehe unten -- ein Klick ins Bild platziert ihn
dann sofort, ohne extra einen Knopf suchen zu muessen):

  - Klick auf seinen Eintrag in der Liste, ODER
  - Klick auf sein Rechteck direkt im Thermobild.

Die Detailansicht des ausgewaehlten Messbereichs enthaelt (Farbe +
"Messbereich setzen"/"Messbereich entfernen" kompakt in einer Zeile):

  - Farbfeld (kleines Quadrat)-> Klick oeffnet die Farbauswahl. Die
                                 Farbe gilt fuer das Quadrat im Bild,
                                 den Graphen und die Bild-Beschriftung.
  - "Messbereich setzen"     -> Knopf aktivieren (oder den Messbereich
                                 wie oben beschrieben auswaehlen), dann
                                 einmal in den Bildbereich klicken: der
                                 Messbereich wird dort zentriert neu
                                 gesetzt.
  - "Messbereich entfernen"  -> entfernt dieses ROI vollstaendig
                                 (Rechteck, Beschriftung und Zeitverlauf-
                                 Kurve) -- kann nicht rueckgaengig gemacht
                                 werden.
  - Felder X-Position /
     Y-Position               -> exakte Pixel-Koordinaten des Mittelpunkts.
  - Felder Breite / Hoehe    -> Kantenlaengen in Pixeln, unabhaengig
                                 voneinander einstellbar (siehe unten).
                                 Ist ein Massstab definiert (Abschnitt
                                 11), erscheint darunter zusaetzlich die
                                 reale Groesse in mm.
                                 In jedem der vier Felder (X-/Y-Position,
                                 Breite, Hoehe) wird ein neu eingegebener
                                 Wert sofort mit ENTER (oder beim
                                 Verlassen des Feldes) uebernommen -- ein
                                 Klick auf "Uebernehmen" ist dafuer nicht
                                 zwingend noetig.
  - Rechts, untereinander:
     "Uebernehmen"            -> setzt den Messbereich exakt auf die
                                 eingegebenen Positions-/Breite-/Hoehe-Werte
                                 (identisch zum Druecken von ENTER in einem
                                 der vier Felder).
     "Position/Groesse
      zuruecksetzen"          -> stellt Position und Groesse wieder auf
                                 den zuletzt bewusst gesetzten Stand her
                                 (z.B. nach versehentlichem Verschieben).
     "Quadrieren"             -> uebernimmt die aktuelle Breite als neue
                                 Hoehe (Quadrat), Mittelpunkt bleibt
                                 erhalten. (Weder dieser noch der
                                 "zuruecksetzen"-Knopf entfernt den
                                 Messbereich - dafuer das Haekchen in der
                                 Liste ausblenden ODER den Knopf
                                 "Messbereich entfernen" verwenden, siehe
                                 oben.)

Die Beschriftung eines platzierten Messbereichs direkt im Thermobild
zeigt rechts neben dem Namen (durch Doppelpunkt getrennt, z.B.
"ROI 1: 24,5 °C") zusaetzlich die aktuell gemittelte Temperatur dieses
Messbereichs an -- sie aktualisiert sich automatisch mit jedem
Frame-Wechsel.

Ein bereits platzierter Messbereich laesst sich auch direkt im Bild mit
der Maus verschieben und in der Groesse aendern. Dabei gibt es ZWEI
Arten von Ziehpunkten (Handles):

  - An den vier ECKEN: proportionale Skalierung - das Seitenverhaeltnis
    (Breite zu Hoehe) bleibt beim Ziehen erhalten.
  - An den vier KANTEN (Mitte jeder Seite): es aendert sich nur die
    jeweils betroffene Dimension (Breite ODER Hoehe), die andere bleibt
    unveraendert.

So laesst sich ein Messbereich frei rechteckig formen, nicht nur
quadratisch. Der Knopf "Quadrieren" macht ein verzerrtes Rechteck bei
Bedarf wieder zum Quadrat (die Breite bleibt dabei massgeblich, die
Hoehe wird an sie angeglichen).

Neu platzierte Messbereiche starten quadratisch mit 30 px Kantenlaenge;
danach laesst sich Breite/Hoehe wie oben beschrieben frei anpassen.

AUSWERTUNGSSTART/-ENDE FESTLEGEN:
Unterhalb des Bildes gibt es in der zweiten Zeile der Zeitleiste die
Felder "Auswertungsstart:" und "Auswertungsende:" -- standardmaessig der
erste bzw. jeweils letzte geladene Frame, per Zahl frei aenderbar (z.B.
wenn eine Aufnahme vor/nach dem eigentlich interessanten Zeitraum noch
weiterlief). Beide werden zusaetzlich direkt im Frame-Regler als kleine
gruene (Start) bzw. rote (Ende) Markierung angezeigt -- diese Markierungen
lassen sich auch DIREKT MIT DER MAUS im Frame-Regler verschieben, ohne
Umweg ueber die Zahlenfelder. Start darf dabei nie hinter das Ende geraten
(und umgekehrt): wird eine Grenze ueber die andere hinaus verschoben,
folgt die andere automatisch nach.

Die Tasten "Pos1"/"Ende" sowie "Start festlegen"/"Ende festlegen" bei der
Verlaufs-Interpolation (siehe unten) springen zu diesem Auswertungsstart/
-ende, nicht zwingend zum ersten/allerletzten Frame der Datei. Auch die
Wiedergabe (Play) bleibt standardmaessig auf diesen Bereich begrenzt --
siehe Abschnitt 5.

VERLAUFS-INTERPOLATION (bewegte Messbereiche):
Manche Messobjekte bewegen sich waehrend der Aufnahme im Bild (z.B.
durch Kamera- oder Objektdrift). Dafuer gibt es je Messbereich die
Checkbox "Position/Groesse ueber Zeit interpolieren (Start -> Ende)".
Standardmaessig AUS - ohne Aktivierung bleibt ein Messbereich wie
bisher fest an einer Stelle stehen.

Bei Aktivierung stehen zwei Knoepfe zur Verfuegung, die jeweils in ZWEI
Schritten bedient werden. Waehrend der Erfassung treten alle ANDEREN
Messbereiche im Bild stark verblasst in den Hintergrund, damit der
gerade bearbeitete eindeutig im Fokus steht:
  1. Auf "Start festlegen (1. Bild)..." klicken -> das Programm springt
     automatisch zum AUSWERTUNGSSTART (siehe oben), aktiviert zugleich
     "Messbereich setzen" und der Knopf beschriftet sich um in "Start
     uebernehmen". Jetzt den Messbereich dort per Klick ins Bild neu
     setzen (auch wenn er zuvor noch gar nicht platziert war) oder per
     Maus/Eingabefeldern korrekt positionieren.
  2. Erneut auf denselben Knopf ("Start uebernehmen") klicken, um die
     jetzt eingestellte Position/Groesse als Start-Punkt zu speichern.
     Der Knopf beschriftet sich danach wieder zurueck.
  3. Genauso mit "Ende festlegen (letztes Bild)..." verfahren: erster
     Klick springt zum AUSWERTUNGSENDE (siehe oben) und beschriftet den
     Knopf zu "Ende uebernehmen" um -- der Messbereich selbst zeigt jetzt
     leicht verblasst noch die Start-Geometrie, deutlich weniger stark
     verblasst als die anderen Messbereiche. Dort den Messbereich
     positionieren (Position und/oder Groesse duerfen sich vom Start
     unterscheiden), zweiter Klick auf "Ende uebernehmen" speichert den
     Ende-Punkt und stellt alle Messbereiche wieder normal sichtbar dar.
     (Start und Ende haben bewusst unterschiedliche Beschriftungen, auch
     wenn beide Knoepfe gleichzeitig auf "uebernehmen" stehen sollten.)
  4. Sobald beide Punkte gesetzt sind, berechnet das Programm fuer alle
     Frames dazwischen die passende Zwischenposition/-groesse linear
     ueber den FRAME-INDEX zwischen Start- und Ende-Bild (nicht ueber
     reale Zeitstempel -- so ist sichergestellt, dass die Bewegung
     tatsaechlich ueber die GESAMTE gewaehlte Bildspanne verteilt ist und
     ihr Ziel exakt erst im Ende-Bild erreicht, auch bei unregelmaessig
     getakteten Aufnahmen mit Pausen dazwischen). Der Messbereich
     "wandert" beim Abspielen/Scrubben entsprechend mit, und auch der
     Temperaturverlauf-Graph wird aus den jeweils korrekten, interpolierten
     Bildausschnitten berechnet.

7. LEGENDE / FARBSKALA
================================================================

Rechts neben dem Bild liegt die Farbskala (Histogramm/Legende):

  - Die beiden Grenzen der farbigen Markierung lassen sich direkt mit
    der Maus verschieben, um den dargestellten Temperaturbereich
    (Kontrast) anzupassen (nur im Modus "Manuell", siehe unten).
  - Rechtsklick auf die Farbskala oeffnet ein Menue mit alternativen
    Farbverlaeufen.
  - Im Panel "ROI & Legende" oben gibt es zusaetzlich:
      * Dropdown "Farbverlauf"    -> Auswahl der Farbpalette: u.a.
                                      "Ironbow" (klassische Waermebild-
                                      Optik), "Inferno", "Plasma",
                                      "Viridis", "Magma", "Turbo",
                                      "Graustufen", "Hot", "Cividis",
                                      "Coolwarm" und "Rainbow". Kalt
                                      erscheint dabei stets dunkel,
                                      heiss stets hell.
      * Checkbox "Invertieren"    -> kehrt den gewaehlten Farbverlauf um
                                      (kalt/warm vertauscht). Steht direkt
                                      unter der Farbverlauf-Auswahl, mit
                                      dieser eingerueckt, da sie inhaltlich
                                      dazugehoert.
      * "Automatisch:"             -> Radioknopf, schliesst sich mit
                                      "Manuell:" gegenseitig aus (immer
                                      genau einer von beiden aktiv).
                                      Darunter zwei Varianten (nur bei
                                      aktivem "Automatisch" bedienbar):
                                      "Pro Bild" (Min/Max werden je Frame
                                      neu berechnet) und "Ueber gesamte
                                      Messung" (Min/Max werden EINMAL ueber
                                      ALLE geladenen Frames ermittelt und
                                      durchgehend verwendet -- nuetzlich,
                                      um die Farbskala ueber die gesamte
                                      Aufnahme vergleichbar zu halten,
                                      statt sie pro Bild neu zu strecken;
                                      Standard).
      * "Manuell:"                 -> Radioknopf, darunter die Felder
                                      "Max"/"Min" (in dieser Reihenfolge)
                                      fuer feste, selbst gewaehlte
                                      Grenzwerte.

8. ZEITVERLAUF-GRAPH UND LIVE-GRAPH
================================================================

Rechts befinden sich zwei Reiter/Tabs (per Klick auf den Titel oben
umschaltbar, oder als eigenes Fenster abtrennbar - siehe Abschnitt 13):

  - "Zeitverlauf"   -> zeigt fuer jeden platzierten und sichtbaren
                       Messbereich den gemittelten Temperaturwert ueber
                       alle geladenen Frames hinweg. Eine gestrichelte
                       senkrechte Linie markiert den aktuell
                       angezeigten Frame.

                       Checkbox "Live-Cursor-Kurve zusätzlich anzeigen"
                       (Standard: AUS) blendet zusaetzlich die Live-
                       Cursor-Kurve (siehe unten) direkt in DIESEM
                       Graphen mit ein -- nuetzlich, um Messbereiche
                       und eine frei gewaehlte Cursor-Stelle gemeinsam
                       zu vergleichen. Unabhaengig von dieser Checkbox
                       ist die Live-Cursor-Kurve beim Export dieses
                       Graphen (Abschnitt 9) automatisch mit dabei,
                       sofern gerade eine verfuegbar ist.

  - "Live (Cursor)" -> solange die Maus ueber das Bild bewegt wird,
                       zeigt dieser Graph den Temperaturverlauf GENAU
                       DES PIXELS unter dem Mauszeiger, ueber alle
                       Frames hinweg. Sehr nuetzlich, um schnell einen
                       einzelnen Bildpunkt zu inspizieren, ohne extra
                       einen Messbereich anzulegen.

                       Linksklick ins Bild fixiert diese Stelle (ein
                       Kreuz markiert das Pixel dauerhaft) - der Graph
                       bleibt dann stehen und folgt der Maus nicht mehr,
                       z.B. um den Wert in Ruhe abzulesen oder die
                       Grafik zu exportieren (siehe Abschnitt 9).
                       Rechtsklick ins Bild hebt die Fixierung wieder
                       auf, der Graph folgt danach wieder der Maus.

Standardmaessig wertet der Live-Graph genau EIN Pixel aus. Ueber
"Werkzeuge > Live-Cursor-Bereichsgroesse" in der Menueleiste laesst
sich stattdessen ein quadratischer Bereich um das Cursor-Pixel
(3x3, 5x5, 7x7 oder 10x10 Pixel) waehlen, dessen Mittelwert angezeigt
und exportiert wird - nuetzlich bei verrauschten Einzelpixeln. Die Wahl
wird gemerkt und liegt bewusst NICHT im rechten Panel, sondern als
eigenes Menue oben.

Bei nur sehr wenigen Frames (z.B. nur 1-2) werden zusaetzlich kleine
Punktmarker auf den Kurven angezeigt, da eine Linie erst ab zwei
Punkten sichtbar waere.

Unten rechts an beiden Graphen laesst sich per Dropdown "Zeitachse"
zwischen "Uhrzeit" (echtes Datum/Uhrzeit, Standard) und "Laufzeit"
(relative Zeit seit Aufnahmebeginn, Format HH:MM:SS) umschalten. Beide
Umschalter sind miteinander synchronisiert (beide Graphen zeigen immer
denselben Modus), da sie dieselbe Zeitachse abbilden.

Daneben (links vom Dropdown) befinden sich zwei weitere Knoepfe:

  - "Achsen zuruecksetzen" -- setzt Zoom/Verschieben GENAU dieses
    Graphen wieder auf den kompletten Datenbereich zurueck, falls per
    Maus (Ziehen/Mausrad) verzoomt oder verschoben wurde.
  - "Achsen einstellen..." -- oeffnet einen Dialog fuer GENAU diesen
    Graphen mit voller Kontrolle ueber:
      * X-Achse (Zeit): wahlweise automatisch oder ein manuell
        eingegebener Wertebereich (in Sekunden seit Aufnahmebeginn).
        Eine feste Schrittweite ist fuer die Zeitachse absichtlich NICHT
        waehlbar -- sie waehlt automatisch gut lesbare Kalenderabstaende
        (z.B. alle 5/15/30 Minuten statt krummer Sekundenwerte).
      * Y-Achse (Temperatur): wahlweise automatisch oder ein manueller
        Wertebereich (Min/Max in °C) UND unabhaengig davon wahlweise
        automatisch oder eine manuelle Schrittweite (Hauptintervall in
        °C) fuer die Beschriftung.
    Alle vier Einstellungen (X-Bereich, Y-Bereich, Y-Schrittweite) lassen
    sich unabhaengig voneinander auf Automatisch zurueckstellen.

Per Rechtsklick direkt auf einen der beiden Graphen bietet pyqtgraph
selbst zusaetzlich ein Kontextmenue (unabhaengig von der App) mit u.a.:

  - "View All" -- wie "Achsen zuruecksetzen" oben, nur an anderer Stelle.
  - "X axis"/"Y axis" -- je ein Untermenue mit "Auto"/"Manual"-Wahl fuer
    den Wertebereich UND einem "Link Axis"-Dropdown: verknuepft die
    X- bzw. Y-Achse DIESES Graphen mit der eines ANDEREN, gerade
    sichtbaren Graphen-Fensters, sodass beide beim Zoomen/Verschieben
    synchron bleiben -- nur relevant, falls mehrere eigene
    pyqtgraph-Fenster nebeneinander geoeffnet sind; fuer die normale
    Bedienung dieser App ohne Nutzen (in der App selbst empfiehlt sich
    stattdessen "Achsen einstellen..." oben).
  - "Mouse Mode" -- wechselt zwischen "3 button" (Standard: Ziehen mit
    der linken Maustaste verschiebt den sichtbaren Ausschnitt) und
    "1 button" (Ziehen zieht stattdessen ein Zoom-Rechteck auf). Reine
    Geschmackssache/Bedienvorliebe.
  - Weitere, fuer eine einfache Temperatur-ueber-Zeit-Kurve nicht
    hilfreiche Punkte ("Transforms", "Downsample", "Average", "Alpha",
    "Points") sind in dieser App ausgeblendet; "Grid" (Gitternetz
    ein-/ausblenden) bleibt verfuegbar.


================================================================
9. GRAFIK UND WERTE EXPORTIEREN
================================================================

Alle Export-Funktionen sind zentral im Menue "Export" oben in der
Menueleiste erreichbar - je EIN Eintrag fuer "Grafik exportieren..."
und "Werte exportieren...": beide Dialoge fragen selbst ab,
welche Kurve(n) (Zeitverlauf/Messbereiche und/oder Live-Cursor)
tatsaechlich mit hinein sollen, statt getrennter Menuepunkte pro Kurve.
Ein Rechtsklick direkt auf den Zeitverlauf- oder Live-Graphen bietet
zusaetzlich den Eintrag "Grafik speichern..." als Abkuerzung fuer GENAU
denselben Export wie "Export > Grafik exportieren..." (identisches
Fenster, identisches Ergebnis inkl. Thermobild) - nur der Umweg ueber
die Menueleiste entfaellt. Ein Rechtsklick direkt auf das Thermobild
exportiert (da es dafuer keine eigene Menue-Entsprechung gibt)
weiterhin nur dieses eine Bild allein, mit demselben Fenster, aber ohne
die Kombiniert/Getrennt-Auswahl.

GRAFIK SPEICHERN (Thermobild + Kurve):
Die exportierte Grafik zeigt das Thermobild mit der Position der
Messbereiche zusammen mit dem zugehoerigen Temperaturverlauf, damit auf
einen Blick nachvollziehbar ist, WO im Bild gemessen wurde und WIE sich
die Temperatur dort entwickelt hat.

  1. "Graph-Inhalt" -> per Checkbox waehlen, welche Kurve(n) exportiert
     werden: JEDER platzierte Messbereich einzeln ("Alle auswaehlen"/
     "Keine auswaehlen" schaltet alle auf einmal um, Standard: alle an)
     und/oder "Live-Cursor" (nur anwaehlbar, wenn gerade ein Live-Cursor-
     Pixel verfuegbar ist, siehe Abschnitt 8; Standard: aus). Alle
     angehakten Kurven erscheinen gemeinsam IM SELBEN Graphen. Mindestens
     eine Kurve muss angehakt sein.
  2. Aufloesung in DPI eingeben (z.B. 150 fuer Bildschirm, 300-600 fuer
     Druck/Berichte).
  3. Waehlen, ob Bild und Kurve KOMBINIERT (eine Grafik, Bild oben/Kurve
     unten) oder GETRENNT (zwei einzelne Dateien "..._Bild" und
     "..._Kurve") gespeichert werden sollen. Die Wahl wird gemerkt.
  4. "Farbskala / Legende" -> dieselbe Freiheit wie im Hauptfenster: entweder
     "Aktuelle Anzeige-Einstellungen uebernehmen" (Standard) oder "Eigene
     Einstellungen fuer diesen Export" mit eigenem Farbverlauf,
     Invertierung, Skalierungsmodus (Abschnitt 7) und Min/Max NUR fuer
     diese eine Grafik -- die Anzeige im Hauptfenster bleibt danach
     unveraendert.
  5. "Zeitachse:" (nur bei Export mit Kurve) -> "Uhrzeit", "Laufzeit" oder
     "Beide" -- vorbelegt mit dem gerade im Hauptfenster aktiven
     Umschalter (Abschnitt 8), unabhaengig davon aber frei aenderbar.
     "Beide" fuegt eine ZWEITE Achse oben am Graphen hinzu, sodass Uhrzeit
     UND Laufzeit gleichzeitig in EINER Grafik zu sehen sind (statt wie
     sonst nur eine der beiden).
  6. "Cursor-Position im Bild anzeigen" (Standard: AUS) -- blendet das
     Fadenkreuz samt Temperaturanzeige am fixierten/zuletzt angefahrenen
     Cursor-Pixel (siehe Abschnitt 8) im Thermobild mit ein. Bleibt der
     Haken leer, enthaelt die Grafik unabhaengig vom aktuellen
     Bildschirmzustand KEINE Maus-Markierung. Unabhaengig von der
     "Live-Cursor"-Kurve unter Punkt 1 einzeln schaltbar -- BEIDE
     zusammen sind moeglich (Cursor im Bild UND seine Kurve im Graphen),
     ebenso NUR der Cursor im Bild ohne Kurve. Die Kurve allein OHNE
     Cursor im Bild ist dagegen nicht sinnvoll: ein Anhaken von
     "Live-Cursor" aktiviert diese Option automatisch mit; ein
     nachtraegliches Abhaken hier deaktiviert dann auch die Kurve wieder.
  7. Dateiname und -format waehlen: PNG, JPEG, BMP, TIFF, WebP oder SVG
     (Vektorgrafik - die Kurve bleibt darin als editierbarer Vektorpfad
     erhalten, das Thermobild selbst ist naturgemaess ein Rasterbild).
  8. Zusaetzlich entsteht eine gleichnamige ".json"-Datei mit
     Metadaten: Koordinaten, Groesse (px und, falls ein Massstab
     definiert ist, auch mm), Name und Farbe jedes Messbereichs,
     Quellordner, Anzahl der Frames, alle Zeitstempel und verwendete
     DPI - damit sich spaeter rekonstruieren laesst, wo die
     Messbereiche im Bild lagen, als die Grafik erzeugt wurde.

Das exportierte Thermobild ist dabei stets so eng wie moeglich
zugeschnitten: unnoetiger Leerraum zwischen Bild und Y-Achse bzw.
zwischen Bild und Farbskala (durch das feste Bild-Seitenverhaeltnis bei
"krummen" Bildschirm-/Exportgroessen) wird automatisch entfernt, Achse
und Farbskala schliessen direkt am Thermobild an.

WERTE EXPORTIEREN ("Export > Werte exportieren..."):
Fuer die reinen Zahlen zur Weiterverarbeitung (z.B. Excel, Python). Nur
EIN Export-Fenster fuer Messbereichs- UND Live-Cursor-Werte (statt
frueher getrennter Exporte):

  - Ganz oben im Dialog waehlt "Format:" zwischen drei Dateiformaten:
      * CSV (Standard) -- ';'-getrennt mit Dezimalkomma, wie die
        Rohdaten, damit sie sich in einem deutsch lokalisierten Excel
        ohne Nacharbeit oeffnen laesst.
      * Text -- inhaltlich identisch zu CSV, nur Tabulator- statt
        ';'-getrennt (z.B. zum Einfuegen in Word/Notepad).
      * JSON -- eine Liste von Datensaetzen (ein Objekt pro Frame,
        Spaltennamen als Schluessel), mit echten Zahlen im JSON-
        ueblichen Dezimalpunkt-Format statt Text mit Dezimalkomma --
        zur Weiterverarbeitung in Skripten/Programmiersprachen.
  - Danach erscheint ein Auswahl-Dialog ("Werte exportieren"): links eine
    Checkbox je platziertem Messbereich, mit der er vom Export
    ausgeschlossen werden kann (Standard: ALLE ausgewaehlt, ueber "Alle
    auswaehlen"/"Keine auswaehlen" auch auf einen Schlag umschaltbar) -
    nuetzlich, wenn z.B. bei "beliebig vielen" angelegten Messbereichen
    nur ein Teil davon in die Datei soll. Ist gerade ein Live-Cursor-
    Pixel verfuegbar (Maus ueber dem Bild bewegt oder eine Stelle
    fixiert, siehe Abschnitt 8), erscheint zusaetzlich eine Zeile "Live
    (Cursor)" in derselben Liste -- so landen Messbereichs- UND Live-
    Cursor-Werte auf Wunsch in EINER gemeinsamen Datei. Daneben laesst
    sich die Spaltenueberschrift jedes (ausgewaehlten) Eintrags frei
    anpassen (voreingestellt ist der jeweilige Name). Je Eintrag gibt es
    zwei ankreuzbare Einheiten ("px"/"mm", mm nur verfuegbar wenn ein
    Massstab definiert ist, siehe Abschnitt 11; Standard: BEIDE aus): ein
    Klick auf "px" oder "mm" traegt die angehakten Einheiten SOFORT
    gemeinsam in den Spaltennamen ein (z.B. bei px+mm beides angehakt:
    "ROI 1 (30x30 px, 10,0x10,0 mm)") -- kein separater Knopf noetig. Der
    Text laesst sich danach auch komplett von Hand ueberschreiben. Oben in
    der Kopfzeile schalten "ALLE px"/"ALLE mm" die jeweilige Einheit fuer
    alle Zeilen auf einmal um (und zeigen automatisch an, ob bereits
    ueberall angehakt ist).
  - Unabhaengig vom gewaehlten Format enthaelt die Datei genau ZWEI
    Zeitspalten - "Zeitstempel" (echtes Datum/Uhrzeit aus dem Dateinamen)
    und "Laufzeit (HH:MM:SS)" (relative Aufnahmedauer, beginnend bei
    00:00:00) - gefolgt von einer Spalte je AUSGEWAEHLTEM Eintrag (bei
    allen 5 Standard-Messbereichen plus Live-Cursor ohne Abwahl also
    8 Spalten insgesamt). Ist die Zeile "Live (Cursor)" mit dabei, stehen
    davor zusaetzlich zwei feste Spalten "Live X-Achse"/"Live Y-Achse"
    mit der (ueber die gesamte Aufnahme konstanten) Pixel-Position des
    Cursors.

10. VIDEO / BILDSTAPEL EXPORTIEREN
================================================================

Ueber "Export > Video / Bildstapel exportieren..." laesst sich die
geladene Serie entweder als MP4-, AVI- oder WebM-Video ODER als
Bildstapel (eine einzelne Bilddatei pro Frame im gewaehlten Ordner)
speichern - ganz oben im Dialog per "Ausgabeform" waehlbar:

  - "Video-Datei (MP4/AVI/WebM)" (Standard) -> Dateiformat wird beim
    anschliessenden Speichern-Dialog ueber die Endung/den Dateityp-
    Filter gewaehlt.
  - "Bildstapel (eine Bilddatei pro Frame)" -> zusaetzlich waehlbar:
    Bildformat (PNG, JPEG, BMP, TIFF oder WebP) und ein gemeinsamer
    Dateiname-Praefix (Standard "Frame_"), der DIREKT (ohne automatisch
    eingefuegtes Trennzeichen) vom fortlaufenden Frame-Index gefolgt wird
    -- ein Trennzeichen wie "_" ans Ende des Praefix selbst mit eintippen.
    Der Praefix versteht dieselben Zeitstempel-Platzhalter wie das
    Namensschema beim Laden (YYYY/MM/DD/hh/mm/ss, siehe Abschnitt 3),
    die mit dem ECHTEN Zeitstempel jedes einzelnen Frames gefuellt werden
    (sofern die Original-Daten diese Information enthalten). Beispiel bei
    3 exportierten Frames mit Praefix "Frame_YYYY-MM-DD_hh-mm-ss_":
      Frame_2026-01-01_12-00-00_1.png
      Frame_2026-01-01_12-00-01_2.png
      Frame_2026-01-01_12-00-02_3.png
    (die Anzahl der Index-Ziffern richtet sich nach der Gesamtzahl der
    exportierten Frames). Statt einer einzelnen Datei wird anschliessend
    ein ZIELORDNER gewaehlt, in den alle Bilder geschrieben werden. Die
    "Wiedergabe-FPS" hat fuer den Bildstapel keine Bedeutung (Feld bleibt
    ausgegraut) - alle uebrigen Einstellungen (Frame-Bereich,
    Farbskala/Legende, Temperaturverlauf-Graph, Cursor im Bild,
    Zeitanzeige im Bild) gelten identisch fuer beide Ausgabeformen.

Alle uebrigen Einstellungen im Dialog:

  - Von-Frame / Bis-Frame  -> nur ein Ausschnitt der Serie exportieren
                               (z.B. nur Frame 40 bis 100), vorbelegt mit
                               dem aktuell im Hauptfenster gesetzten
                               Auswertungsstart/-ende (Abschnitt 4).
  - Wiedergabe-FPS          -> Abspielgeschwindigkeit im fertigen Video
                               (ohne Bedeutung/ausgegraut beim Bildstapel).
  - "Farbskala (Legende) einblenden" -> ein-/ausschaltbar. Falls
    eingeblendet, zusaetzlich waehlbar:
      * "Aktuelle Anzeige-Einstellungen uebernehmen" -> verwendet
        Farbverlauf und Skalierungsmodus (Abschnitt 7) genau so, wie
        sie gerade im Hauptfenster eingestellt sind.
      * "Eigene Einstellungen fuer dieses Video" -> Farbverlauf,
        Invertierung, Skalierungsmodus und Min/Max werden nur fuer
        diesen einen Export separat festgelegt, die Anzeige im
        Hauptfenster bleibt danach unveraendert.
  - "Temperaturverlauf-Graph" -> "Graph mit exportieren" (Standard: AUS)
    blendet zusaetzlich einen Kurven-Graphen mit ein -- mit derselben
    wandernden Zeit-Markierungslinie, die auch im Hauptfenster den
    aktuellen Frame auf der Kurve anzeigt, also genau wie in der
    Anwendung selbst. "Graph-Inhalt" darunter waehlt PER CHECKBOX, welche
    Kurve(n) darin erscheinen: jeder platzierte Messbereich einzeln
    (Standard: alle an) und/oder "Live-Cursor" (nur verfuegbar, wenn
    gerade ein Live-Cursor-Pixel vorliegt, siehe Abschnitt 8; Standard:
    aus) -- genau wie beim Grafik-Export (Abschnitt 9). "Position:" legt
    fest, WO der Graph relativ zum Thermobild sitzt: Unter/Über/Links/
    Rechts vom Bild (frei waehlbar). Dieser gesamte Kasten betrifft NUR
    den Kurven-Graphen -- nicht das Thermobild selbst.
  - "Cursor im Bild" -> EIGENER, vom Graphen UNABHAENGIGER Kasten (bewusst
    NICHT Teil von "Temperaturverlauf-Graph", auch bei ausgeschaltetem
    "Graph mit exportieren" bedienbar): "Cursor-Position im Bild anzeigen"
    (Standard: AUS) blendet das Fadenkreuz samt Temperaturanzeige am
    fixierten/zuletzt angefahrenen Cursor-Pixel im THERMOBILD mit ein,
    unabhaengig von der "Live-Cursor"-Kurve im Graphen einzeln schaltbar
    (die Kurve setzt diese Option allerdings voraus -- ein Anhaken von
    "Live-Cursor" aktiviert sie automatisch mit). Bleibt der Haken leer,
    enthaelt der Export KEINE Maus-Markierung im Bild.
  - "Zeitanzeige im Bild" -> blendet unten im Bild einen Streifen ein,
    waehlbar als 2x2-Auswahl (Namen bewusst wie im uebrigen Programm, mit
    Tooltip bei Laufzeit/Zeitstempel; Standard: "Beides"). Nicht zu
    verwechseln mit "Zeitachse:" beim Grafik-Export (Abschnitt 9, Punkt 5)
    -- dort geht es um die X-ACHSE des Kurven-Graphen, hier um einen Text/
    Balken, der direkt in das Bild/Video eingebrannt wird:
      * "Laufzeit" -> Fortschrittsbalken mit gruener/roter Markierung
        an der TATSAECHLICHEN Position von Start/Ende des exportierten
        Bereichs INNERHALB DER GESAMTEN Aufnahme (nicht an den Rand der
        Leiste geklemmt), ein blauer Punkt wandert dazwischen mit dem
        aktuellen Frame mit, plus verstrichene/gesamte Laufzeit
        (HH:MM:SS) relativ zum Aufnahmebeginn. Der Video-/Bildstapel-
        INHALT selbst bleibt dabei unveraendert auf den gewaehlten
        Von-/Bis-Frame beschraenkt -- die Leiste zeigt nur zusaetzlich
        dessen Einbettung in die Gesamtaufnahme.
      * "Keine" -> kein Streifen.
      * "Zeitstempel" -> reales Datum/Uhrzeit des jeweiligen Bilds.
      * "Beides" (Standard) -> Fortschrittsbalken UND Zeitstempel
        gemeinsam.

  Hinweis: Der Video-Export (nicht der Bildstapel-Export) benoetigt
  intern das Paket "imageio" (mit "imageio-ffmpeg"). In den fertigen
  exe-/Binaerdateien (siehe Abschnitt 2) ist das bereits enthalten; bei
  einem Start aus dem Quellcode installiert "uv run python run.py" es
  automatisch mit.

Wie beim Bild-Export ist das Thermobild eng zugeschnitten (kein
unnoetiger Leerraum links/rechts zwischen Bild und Achse bzw.
Farbskala, siehe Abschnitt 9).

Der Export laeuft mit Fortschrittsanzeige (abbrechbar). Waehrend des
Renderns bleibt die Anzeige im Hauptfenster unveraendert (keine
sichtbaren Linien-/Schriftgroessen-Sprünge mehr waehrend des Exports) und
wird danach automatisch wieder auf den Anzeigezustand von vor dem Export
zurueckgesetzt.

11. MASSSTAB (LINEAL) UND REALE GRÖSSEN IN MM
================================================================

Ueber "Werkzeuge > Massstab festlegen..." (oder den Knopf
"Festlegen..." im Panel "Massstab") laesst sich eine Referenzlaenge im
Bild definieren:

  1. Startpunkt der Referenzlinie im Bild anklicken - ab hier ist eine
     deutlich sichtbare Linie mit Punktmarkierung zu sehen (Standard-
     farbe kraeftig rot).
  2. Endpunkt anklicken - die Linie zieht sich bis zu dieser Stelle mit.
  3. Im erscheinenden Dialog die reale Laenge dieser Linie in mm
     eingeben (z.B. "30" fuer eine 30 mm lange Referenzstrecke).

Die Referenzlinie bleibt danach direkt im Bild stehen, mit der
eingegebenen mm-Laenge als kleiner Beschriftung darunter - so ist auf
einen Blick nachvollziehbar, welche Strecke dem Massstab zugrunde
liegt. Zusaetzlich zeigt das Panel "Massstab" den ermittelten
Umrechnungsfaktor (z.B. "1 px ≈ 0,42 mm") und bei jedem Messbereich
erscheint zusaetzlich zur Pixel-Groesse die reale Groesse in mm (in
Klammern). Die Handhabung der Messbereiche selbst bleibt weiterhin in
Pixeln - der mm-Wert ist nur eine zusaetzliche Anzeige. Ueber den Knopf
"Entfernen" im Massstab-Panel laesst sich die Umrechnung samt der
eingezeichneten Referenzlinie wieder loeschen.

Die fertige Referenzlinie muss NICHT geloescht und neu gezeichnet
werden, um sie nachtraeglich anzupassen:

  - Beide Endpunkte lassen sich einzeln per Maus verschieben (kleine
    Ziehpunkte an Start/Ende) -- die reale Laenge in mm bleibt dabei
    unveraendert, nur der Umrechnungsfaktor (px zu mm) wird automatisch
    aus der neuen Pixel-Distanz neu berechnet.
  - Ein DOPPELKLICK auf die Linie oder ihre mm-Beschriftung oeffnet
    erneut den Laengen-Dialog, um die reale Laenge selbst zu aendern --
    hier bleiben umgekehrt die aktuellen Endpunkte unangetastet.

Das kleine Farbfeld neben "Entfernen" oeffnet die Farbauswahl fuer die
Referenzlinie -- nuetzlich, falls die Standardfarbe bei einem bestimmten
Farbverlauf (z.B. "Hot", der ebenfalls viel Rot enthaelt) kaum zu
erkennen ist.

Der Massstab wird beim Speichern eines Projekts (Abschnitt 12) mit
gesichert und laesst sich beim CSV-Export als "mm"-Autofill fuer
Spaltennamen nutzen (Abschnitt 9).


================================================================
12. PROJEKT SPEICHERN UND LADEN
================================================================

Ueber das Menue "Datei" lassen sich die Einstellungen einer Sitzung
(NICHT die Messdaten selbst) in einer kleinen Projektdatei sichern -- wie
z.B. ein Auswertungs-Speicherstand in Origin, den man spaeter zusammen
mit den Rohdaten wieder oeffnet:

  - "Projekt speichern..." -> schreibt Position, Groesse, Name, Farbe
                              und Sichtbarkeit aller Messbereiche sowie
                              Farbverlauf, Legenden-Limits, Massstab
                              (inkl. Referenzlinien-Farbe), Auswertungs-
                              start/-ende UND den Quellordner der
                              Messreihe in eine Datei mit Endung
                              ".tvproj".
  - "Projekt laden..."     -> wendet eine zuvor gespeicherte
                              ".tvproj"-Datei an.

Ist beim Laden bereits eine Messreihe geoeffnet, wird das Projekt direkt
darauf angewendet. Ist NOCH KEINE Messreihe geladen (z.B. frischer
Programmstart, direkt "Projekt laden..." angeklickt), laedt die App
automatisch den beim Speichern hinterlegten Quellordner mit nach --
KEIN vorheriges manuelles "Ordner öffnen..." mehr noetig. Nur falls
dieser Ordner nicht mehr existiert (z.B. verschoben/umbenannt/auf einem
anderen Rechner geoeffnet), fragt die App EINMALIG nach dem passenden
Ordner.

Nuetzlich, um bei wiederkehrenden Messungen (z.B. derselbe Pruefstand)
nicht jedes Mal alle Messbereiche neu platzieren zu muessen. Wird ein
Projekt auf eine Messreihe aus einem anderen Quellordner als beim
Speichern angewendet, erscheint ein Hinweis - die Messbereiche sollten
dann kurz auf Plausibilitaet geprueft werden (z.B. falls sich die
Bildaufloesung unterscheidet).


================================================================
13. FENSTER/PANELS ANORDNEN
================================================================

Die drei rechten Panels ("ROI & Legende", "Zeitverlauf",
"Live (Cursor)") lassen sich wie in professionellen Programmen ueblich:

  - in der Breite verstellen (Rand mit der Maus ziehen)
  - links oder rechts andocken (am Titel packen und verschieben)
  - schliessen (X-Knopf oben am Panel) und ueber das Menue
    "Ansicht" wieder einblenden
  - als eigenes, frei verschiebbares Fenster abdocken (Titel packen
    und aus dem Hauptfenster herausziehen)

Das Menue "Ansicht" bleibt (anders als sonst in Qt-Menues ueblich) nach
dem Anklicken einer Checkbox (Panel-Sichtbarkeit, Dunkelmodus) GEOEFFNET,
statt sich sofort zu schliessen -- so lassen sich mehrere Haekchen
nacheinander setzen, ohne das Menue jedes Mal neu aufklappen zu muessen.
Es schliesst sich erst bei einem Klick ausserhalb des Menues oder auf
einen nicht-ankreuzbaren Eintrag.


================================================================
14. HINWEISE UND PROBLEMBEHEBUNG
================================================================

- "Ich sehe im Graph nur einzelne Punkte, keine Linie."
  -> Es sind (noch) zu wenige Frames geladen (z.B. nur 1). Sobald
     mehrere Frames mit unterschiedlichen Zeitstempeln vorliegen,
     erscheint automatisch eine durchgezogene Linie.

- "Warnung: doppelte Zeitstempel erkannt."
  -> Mindestens zwei geladene Dateien haben denselben Zeitstempel im
     Dateinamen (haeufig durch Kopieren/Umbenennen einer Testdatei).
     Fuer echte Messreihen sollte jede Datei einen eigenen, eindeutigen
     Zeitstempel im Namen tragen.

- "Das Bild laesst sich nicht verschieben/zoomen."
  -> Das ist Absicht, siehe Abschnitt 4.

- "Welche exe (windows10-11 / windows7-legacy) brauche ich?"
  -> Windows 10 oder 11: die normale "windows10-11"-Variante.
     Windows 7: die "windows7-legacy"-Variante. Diese basiert bewusst
     auf einem aelteren, aber Windows-7-faehigen Software-Stand.

- "Beim Laden werden einzelne Dateien uebersprungen."
  -> Siehe Abschnitt 3: einzelne kaputte/unlesbare Dateien oder Frames
     mit abweichender Bildaufloesung werden automatisch uebersprungen,
     damit der Rest der Messreihe trotzdem nutzbar bleibt. Die Warnung
     listet Dateiname und Grund je uebersprungener Datei auf.

- "Projekt laden veraendert meine Messbereiche nicht wie erwartet."
  -> Pruefen, ob wirklich zuerst die passende Messreihe geladen wurde
     (siehe Abschnitt 12) - eine ".tvproj"-Datei enthaelt nur
     Einstellungen, keine Messdaten.


================================================================
15. TECHNISCHE DETAILS ZUM DATEIFORMAT
================================================================

Erwartetes CSV-Format je Messdatei:
  - Eine Zeile pro Bildzeile der Thermokamera
  - Werte durch Semikolon (;) getrennt
  - Dezimalkomma statt Dezimalpunkt (deutsches Format), z.B. "28,6"

Zeitstempel: wird aus dem Dateinamen gelesen, im Muster
  Record_JJJJ-MM-TT_HH-MM-SS.csv
Beispiel: Record_2026-07-23_07-43-17.csv
  -> 23. Juli 2026, 07:43:17 Uhr

Enthaelt der Dateiname kein passendes Muster, wird ersatzweise die
Aenderungszeit der Datei im Dateisystem verwendet.
